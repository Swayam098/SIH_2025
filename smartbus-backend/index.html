About SmartBus

This project brings smart, real-time public transport tracking to tier-2 cities:

  • GPS-based bus tracking with ETAs
  • Support for multiple languages (English, Hindi, Tamil)
  • Interactive SMS simulator for low-bandwidth users
  • Open-source prototype for municipalities and transport authorities
